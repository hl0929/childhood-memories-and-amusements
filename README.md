## 音效系统

所有游戏共用根目录的 [`sound.js`](sound.js)，通过 Web Audio API 实时合成音效，不加载任何外部音频文件。每个游戏都接入了与玩法对应的声音，例如：

| 场景 | 游戏示例 | 声音设计 |
|------|----------|----------|
| 移动 / 旋转 / 推箱 | 俄罗斯方块、推箱子 | 短促方波与三角波 |
| 碰撞 / 击打 | 打砖块、乒乓球、打地鼠 | 随力度或连击变化的打击音 |
| 消除 / 合并 | 消消乐、2048、连连看 | 音高随连锁或数字递增 |
| 爆炸 / 受伤 | 扫雷、飞机大战 | 低通噪声 + 低频振荡 |
| 胜负 / 升级 | 全部游戏 | 上行或下行琶音 |

**静音方式：** 点击页面右上角的 🔊 按钮，或按 `M` 键。静音状态保存在 `localStorage` 中，所有游戏共用。首次点击 / 按键时才会创建 `AudioContext`，符合浏览器自动播放策略。

## 页面布局

所有游戏共用根目录的 [`common.css`](common.css) 作为布局基础层，各游戏只保留自己的主题与棋盘样式：

- 左上角浮动「返回」按钮，右上角浮动音效按钮，形成统一顶栏
- 使用 `100dvh` + `env(safe-area-inset-*)`，适配移动端浏览器地址栏与刘海屏
- 内容较少时垂直居中；内容超高时从顶部正常滚动，不会裁切标题
- 棋盘 / 画布按视口宽高自动缩放，手机端按钮和棋盘不会横向溢出
- 扫雷高级难度的 30 列棋盘在手机端支持棋盘内横向滑动
- 俄罗斯方块在手机端自动切换为「棋盘 + 底部状态栏 + 虚拟按键」布局，并响应窗口旋转

## 视觉风格（Q 版糖果风）

所有页面统一为明亮、圆润的 Q 版糖果风格：

- 浅奶油 / 粉蓝 / 淡紫渐变背景，移动端浏览器主题色同步为 `#fffaf4`
- 白色「贴纸」卡片、圆角粗描边、柔和糖果色投影
- 每个游戏保留自己的糖果色强调色，用于分数、按钮和棋盘高亮
- 深色游戏画布（贪吃蛇 / 打砖块 / 俄罗斯方块 / 乒乓球 / 飞机大战）作为「游戏屏幕」，用白色 4px 圆角相框包住
- 弹窗为白色圆角卡片，深色画布内的开始 / 暂停遮罩使用白字 + 糖果色光晕
- 视觉变量集中在 `common.css` 的 `--q-*` 与各游戏 `:root` 的 `--accent`

## 运行方式

直接双击任意游戏目录内的 `index.html`，或启动本地服务器后访问主页：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
