# 🎮 休闲小游戏合集

15 款经典小游戏，纯原生 HTML5 + CSS3 + JavaScript 实现，零外部依赖，双击 `index.html` 即可游玩。

## 运行方式

直接双击任意游戏目录内的 `index.html`，或启动本地服务器后访问主页：

```bash
# Python
python -m http.server 8080

# Node.js
npx serve .
```
