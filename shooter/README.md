# 🚀 飞机大战

波次射击游戏，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- 三角战机 + 引擎火焰动画
- 波次递进：每 200 分升级一波，敌机越来越快
- 多血量敌机（3 波以上 30% 概率出现 2HP 敌机，带血条）
- 自动射击（空格 / 触屏持续发射），冷却 8 帧
- 粒子爆炸特效：击毁金色粒子 + 碰撞红色粒子
- 流动星空背景
- 3 条命 + localStorage 持久化最高分
- 移动端触屏拖拽控制 + 自动射击
- 音效：射击、命中、爆炸、受伤、升级与失败音效

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 射击 | 空格（按住连射） |
| 暂停 / 继续 | P |
| 重开 | R |
| 移动端 | 触屏拖拽移动 + 自动射击 |
