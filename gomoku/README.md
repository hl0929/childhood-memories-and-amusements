# 🔴 五子棋

经典五子棋对弈，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- 15×15 木纹棋盘，星位标记（天元 + 四角星）
- 棋子渐变光影 + 阴影效果
- 悬停预览落子（半透明棋子）
- 胜利连线高亮（红色发光）
- AI 评分策略：活四/冲四/活三/冲三/活二/冲二 六级评分
- AI 攻防兼顾：攻击权重 ×1.1 + 防守评分
- 棋盘空时 AI 走天元
- 双人对战 / AI 对战模式切换
- 触屏直接落子 + 坐标缩放
- 音效：落子、非法落子、胜负提示音

## 操作

| 操作 | 方式 |
|------|------|
| 落子 | 点击棋盘交叉点 |
| 悬停预览 | 鼠标移动 |
| 移动端 | 触屏点击 |
| 切换模式 | 点击 vs AI / 双人按钮 |
| 重开 | 点击新局按钮 |
