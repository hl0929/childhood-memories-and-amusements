# 📦 推箱子

经典推箱子游戏，基于 DOM + CSS 实现，零外部依赖。

## 特色

- 10 关关卡，使用标准 Sokoban 符号（#@$.*+）
- 撤销功能（历史栈回溯，按 Z 撤销）
- 箱子到位变色提示
- 移动端触屏滑动操作
- 通关自动检测 + 下一关按钮

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 撤销 | Z |
| 重置本关 | R |
| 移动端 | 触屏滑动 |
