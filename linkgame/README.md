# 🔗 连连看

图案连线消除游戏，基于 DOM + SVG 实现，零外部依赖。

## 特色

- 6×8 棋盘，12 种图案配对
- BFS 寻路（≤ 2 弯连线），路径经过棋盘外围空白区
- SVG 动态连线动画，600ms 后自动消失
- 提示按钮：高亮一对可消除图案（1.6s 脉冲动画）
- 自动打乱：无可用配对时 Fisher-Yates 洗牌
- 计时 + 剩余数量 + 得分
- 音效：选中、消除、提示、洗牌与通关音效

## 操作

| 操作 | 方式 |
|------|------|
| 选中图案 | 点击 |
| 消除配对 | 点击同图案的第二个 |
| 提示 | 点击提示按钮 |
| 打乱 | 点击打乱按钮 |
| 重开 | 点击重新开始 |
