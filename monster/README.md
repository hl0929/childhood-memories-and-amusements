# 👾 怪兽塔防

路径式塔防小游戏，10 个关卡、5 类武器各 3 级、6 种不同等级的怪兽，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- **10 张不同路线图**：怪物从左侧传送门出现，沿路径进攻右侧城堡
- **5 类武器，每类 3 级**：
  - 🏹 箭塔：单体高频输出
  - 💣 炮塔：范围爆炸伤害
  - ❄️ 冰塔：减速敌人
  - ⚡ 电塔：连锁闪电，可同时命中多个目标
  - 🧪 毒塔：持续毒素伤害，无视护甲
- **6 种怪兽等级**：史莱姆、蝙蝠、骷髅、幽灵、巨魔、恶龙
- 怪兽拥有不同生命、速度、护甲、减速抗性和漏怪伤害
- 金币经济：击杀怪物获得金币，用于建造 / 升级 / 出售武器
- 每关 2~3 波，逐关加强；第 10 关有双恶龙 Boss
- 生命值 20，漏怪扣生命；失败可重试本关
- 清除本关奖励金币并恢复生命
- 建造位自动沿路径生成，每关 14 个
- 粒子、血条、减速 / 中毒状态、连锁闪电、爆炸范围、浮动金币
- Web Audio 合成音效；Q 版糖果风页面
- 桌面鼠标 + 手机触屏操作

## 操作

| 操作 | 方式 |
|------|------|
| 选择武器 | 点击下方武器卡片（或数字键 1~5） |
| 建造 | 点击空建造位 |
| 选择已建武器 | 点击武器 |
| 升级 / 出售 | 点击武器后使用浮动面板按钮 |
| 暂停 / 继续 | P / 暂停按钮 |
| 重新开始 | R / 重开按钮 |

## 武器

| 武器 | 造价 | 特点 | 3 级方向 |
|------|------|------|----------|
| 🏹 箭塔 | 40 | 单体高速 | 伤害 / 射程 / 攻速提升 |
| 💣 炮塔 | 70 | 范围爆炸 | 伤害 / 爆炸范围提升 |
| ❄️ 冰塔 | 60 | 减速 | 减速比例 / 持续时间提升 |
| ⚡ 电塔 | 90 | 连锁闪电 | 伤害 / 连锁数提升 |
| 🧪 毒塔 | 80 | 持续毒伤 | 毒素伤害 / 持续时间提升 |

## 怪兽

| 怪兽 | 等级 | 特点 |
|------|------|------|
| 🦠 史莱姆 | 1 | 基础杂兵，数量多 |
| 🦇 蝙蝠 | 1 | 速度快，血量低 |
| 💀 骷髅 | 2 | 有 1 点护甲 |
| 👻 幽灵 | 2 | 减速抗性高 |
| 👹 巨魔 | 3 | 高血量、3 点护甲、漏怪伤害高 |
| 🐉 恶龙 | 4 | Boss，900 生命、5 点护甲 |

## 小提示

- 前期优先箭塔铺场，中期补炮塔处理怪群
- 冰塔放在路径拐角，覆盖更多路段
- 毒塔无视护甲，适合对付巨魔和恶龙
- 电塔连锁适合密集怪群，但单体输出低于箭塔
- 出售返还 60% 投入，可以随时调整布局
- 生命低于 5 时优先升级而不是继续铺塔
