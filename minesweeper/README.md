# 💣 扫雷

经典扫雷游戏，基于 DOM + CSS 实现，零外部依赖。

## 特色

- 三档难度：初级 9×9（10雷）/ 中级 16×16（40雷）/ 高级 16×30（99雷）
- 首击安全：第一次点击不会踩雷，且保证周围 3×3 区域安全
- 空格递归展开：点击空白格自动展开相邻空格
- 右键标旗 + 长按标旗（移动端 400ms 长按触发）
- 实时计时 + 剩余雷数显示
- 踩雷标记（红色爆炸）+ 胜利自动标旗
- 音效：翻格、标旗、踩雷爆炸与胜利音效

## 操作

| 操作 | 方式 |
|------|------|
| 翻开格子 | 点击 |
| 标旗 | 右键 / 长按 400ms |
| 切换难度 | 点击难度按钮 |
| 重开 | R 键 / 点击按钮 |
