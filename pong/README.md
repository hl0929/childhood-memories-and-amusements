# 🏓 乒乓球

经典 Pong 游戏，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- AI / 双人模式切换
- 挡板击球角度反射：击打位置越偏边缘，反弹角度越大
- 球速递增：每次碰撞 +0.2 加速
- 球轨迹拖尾粒子效果（20 帧渐隐）
- 分屏触控：左半屏控制左方，右半屏控制右方
- 先到 7 分获胜
- AI 限速跟踪（3.5px/帧 + 5px 死区）

## 操作

| 操作 | 按键 |
|------|------|
| 左方上下 | W / S |
| 右方上下 | ↑ / ↓（双人模式） |
| 开始 / 重开 | 空格 |
| 暂停 | P |
| 移动端 | 分屏触控拖动 |
