# 🌻 花园保卫战

类似《植物大战僵尸》的植物塔防小游戏，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- 9×5 草坪战场，僵尸从右侧进攻，植物从左侧防守
- 阳光经济：向日葵产阳光，天空定期掉落阳光，点击收集
- 5 种植物：
  - 🌻 向日葵：持续产生阳光
  - 🌱 豌豆射手：攻击同一行的僵尸
  - 🌰 坚果墙：高血量，阻挡僵尸
  - ❄️ 寒冰射手：减速被击中的僵尸
  - 🍒 樱桃炸弹：3×3 范围爆炸
- 4 种僵尸：普通、路障、铁桶、快速
- 8 波进攻，逐波变强；每行最后一辆小推车可救场一次
- 铲子可以移除已种植的植物
- 粒子、血条、减速状态、阳光收集动画
- Web Audio 合成音效：种植、射击、命中、爆炸、收集、波次、胜负
- localStorage 持久化最高分
- 桌面点击 / 键盘 + 手机触屏操作

## 操作

| 操作 | 方式 |
|------|------|
| 选择植物 | 点击下方植物卡片（或数字键 1~5） |
| 种植 | 点击草坪格子 |
| 收集阳光 | 点击阳光 |
| 铲除植物 | 点击铲子，再点击植物 |
| 暂停 / 继续 | P / 暂停按钮 |
| 重新开始 | R / 重开按钮 |

## 植物与僵尸

| 植物 | 阳光 | 作用 |
|------|------|------|
| 向日葵 | 50 | 每 7.5s 产出 25 阳光 |
| 豌豆射手 | 100 | 每 1.2s 发射豌豆 |
| 坚果墙 | 50 | 520 生命，挡住僵尸 |
| 寒冰射手 | 125 | 伤害 + 减速 |
| 樱桃炸弹 | 150 | 0.9s 后 3×3 爆炸 |

| 僵尸 | 生命 | 特点 |
|------|------|------|
| 普通僵尸 | 100 | 基础敌人 |
| 路障僵尸 | 220 | 更耐打，头戴橙色路障 |
| 铁桶僵尸 | 380 | 高血量，头戴铁桶 |
| 快速僵尸 | 80 | 移动速度约 2 倍 |

## 小提示

- 前 15 秒是布防时间，先种 2~3 株向日葵建立经济
- 豌豆射手需要和僵尸在同一行才能攻击
- 坚果墙放在射手前面，给后排争取输出时间
- 樱桃炸弹适合清理扎堆的僵尸
- 每行的小推车只能触发一次，不要把所有僵尸都放到同一行
