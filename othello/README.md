# ⚫️ 黑白棋

经典黑白棋（翻转棋 / Othello），基于 DOM + CSS 实现，零外部依赖。

## 特色

- 标准 8×8 棋盘，初始中央 4 子对角排列
- 翻转动画：棋子 `scaleX` 翻转效果（300ms）
- 合法落子位置高亮提示
- 跳过回合：当前玩家无合法走法自动跳过
- 双方无合法走法 → 自动结算
- AI 对战：贪心策略 + 8×8 位置权重表评估
- 双人对战模式切换
- 棋子计数实时显示
- 音效：落子、翻转、跳过回合与结算音效

## 操作

| 操作 | 方式 |
|------|------|
| 落子 | 点击合法位置 |
| 切换模式 | 点击 vs AI / 双人按钮 |
| 重开 | 点击新局按钮 |
