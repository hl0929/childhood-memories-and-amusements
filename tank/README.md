# 🛡️ 坦克大战

向经典 FC《坦克大战》致敬的俯视角坦克防守游戏，基于 HTML5 Canvas 实现，零外部依赖。

## 特色

- 13×13 战场：砖墙可被炮弹摧毁，钢墙不可破坏
- 基地防守：基地被击毁即失败，需要一边消灭敌人一边保护基地
- 5 个关卡：敌人数量、速度和同屏上限逐关提升
- 敌方 AI：随机巡逻 + 定时开火，会破坏砖墙开辟道路
- 玩家 3 条命，被击毁后原地复活并短暂无敌
- 粒子爆炸、炮口朝向、坦克履带与炮塔绘制
- Web Audio 合成音效：开火、命中、爆炸、受伤、升级、胜负
- localStorage 持久化最高分
- 桌面键盘 + 手机虚拟方向键 / 开火键

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 开火 | 空格 |
| 暂停 / 继续 | P |
| 重新开始 | R |
| 移动端 | 虚拟方向键 + 开火按钮 |

## 小提示

- 优先清理靠近基地的敌人，基地比坦克更脆弱
- 砖墙可以被自己的炮弹打掉，注意不要误伤基地
- 钢墙无法破坏，但可以利用它挡住敌方炮弹
- 敌人会从顶部三个出生点出现，注意分兵防守
