# 🔢 数独

数独益智游戏，基于 DOM + CSS 实现，零外部依赖。

## 特色

- 回溯算法生成合法数独（随机打乱数字顺序保证每局不同）
- 三档难度：简单（36 空）/ 中等（46 空）/ 困难（54 空）
- 笔记模式：格子内 3×3 小数字标记候选值
- 自动清除关联笔记：填入正确数字后自动删除同行/列/宫的笔记
- 错误计数 + 红色标记
- 高亮同行/列/宫 + 高亮相同数字
- 数字键盘 + 键盘输入（1-9 数字 / 方向键移动 / N 切换笔记）
- 数字耗尽提示（9 个全部填完后按钮变灰）
- 实时计时
- 音效：选格、填数、错误、笔记、擦除与通关音效

## 操作

| 操作 | 方式 |
|------|------|
| 选择格子 | 点击 / 方向键 |
| 填数字 | 1-9 键 / 数字键盘 |
| 笔记模式 | N 键 / 笔记按钮 |
| 擦除 | Backspace / Delete / 擦除按钮 |
| 切换难度 | 点击难度按钮 |
| 重开 | 点击重新开始 |
